Student Grade Calculator
Objective
To develop a simple web application that calculates and displays a student's grade based on 
the score entered by the user.
What Was Done
• Created a score input field.
• Implemented grade calculation using JavaScript.
• Added input validation for scores between 0 and 100.
• Displayed results dynamically on the webpage.
• Applied basic CSS styling to improve the user interface.
Challenges
• Connecting the button click event to the grade calculation function.
• Correcting variable naming errors in JavaScript.
• Validating user input to prevent invalid scores.
